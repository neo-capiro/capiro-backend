No live workflow is moved or disabled in capirov2 by this packet.

Quarantine all workflows, including apparent read-only/source jobs, rather than relying on missing secrets or repo-name trust failures. If a stronger repository-wide Actions disable is required, that is a separately reviewed setting change before push, not an action authorized by this preparation. No automatic workflow execution is authorized. Initial CI runs locally/read-only against recorded source; enabling any new workflow is a later approved delta.
