## Available Phase 4 foundations

Phase 5 can consume:

- canonical selected target snapshots;
- campaign-local target recommendation rejection state;
- `search_targets`;
- `get_target_profile`;
- `analyze_relationships`;
- deterministic target health/coverage;
- profile snapshot revalidation;
- proposal-only reasoning target commands.

It must not copy or replace those implementations.

## Phase 5 scope

Phase 5 owns:

- governed context-reference contracts;
- required policy;
- writing guidance;
- campaign facts;
- target-specific context;
- group-safe context;
- exclusions and scope reasons;
- campaign strategy and delivery recommendation support;
- safe context tools for the reasoning gateway.

## Phase 5 invariants

- target-specific context may reach only its named target;
- a target profile fact is not automatically campaign context;
- relationship note bodies remain excluded unless the context system authorizes and scopes them;
- writing guidance is not evidence;
- multi-client confidential context cannot commingle;
- the reasoning model proposes context commands but cannot apply them;
- no generation or send authority is added;
- final UI still waits for approved mockups.

## Known unsupported target sources

Phase 4 does not provide dedicated agency or local-government personnel directories. Phase 5 must not invent those targets while adding context/strategy.
