## Repeatable checks

Run the dedicated Phase 2 steps in `.github/workflows/legiwatch-ci.yml` after generating both Prisma clients and applying the complete API then Intel migration chains to a disposable database named `capiro`. Run database suites sequentially: older integration fixtures use `TRUNCATE ... CASCADE` across shared tables. Do not run those fixtures concurrently with Phase 2 PostgreSQL suites against the same database.

The broader gate enumerates API, Intel and web LegiWatch paths and asserts minimum suite/test counts. Preserve these assertions; do not hide failures by omitting suites. `render-report-qualification.ts` writes the six synthetic HTML/text/JSON output variants outside the repository when given an output directory.
