# Phase 7 research navigation qualification

Research supports selecting a separate bill and session on the right while retaining the left source and both exact revisions. The picker searches retained bill texts, states its coverage boundary, and preserves choices in the URL. Cross-session draft saves explicitly bind each selected document to the primary or selected right session; unrelated session IDs are rejected.

The version controls distinguish current extraction, newest retained publisher date (including ties, omitting undated text), enrolled text and chaptered text. Publisher labels are separate from operative legal effect; none establishes that a particular provision became effective. The selected corpus can still be incomplete.

Private folder/client names come from current authorized reads. Analysis, the unchanged save request key and the resulting selection/draft IDs recover after a reload within the same browser tab. This local recovery is isolated by authenticated tenant/user, private scope, source pair and exact revisions; authoritative Workspace/report access is rechecked by the server. PDF diff passages link to their own original source page. HTML sources retain the exact source link without inventing an anchor.

Local validation: 37 Intel checks on a fresh disposable database, eight component/recovery checks, and Intel/Web typechecks. One initial local rerun used an old test database containing a synthetic qualification receipt; its expected missing-receipt assertion failed. A fresh database passed all checks. No live qualification receipt was created. Native build and deployment evidence are recorded separately in the release checkpoint.

This closes implementation gaps found during the live internal source-to-draft-to-report walkthrough. Human source labels, current client configuration ownership, recipient decisions and client acceptance remain separate gates. The owned internal verification report is technical evidence, not human or client approval of legal conclusions. No external delivery is enabled by this change.
