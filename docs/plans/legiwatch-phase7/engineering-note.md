# Phase 7 legislative research

Phase 7 extends the existing API evidence, Intel folder/report/workflow owners, Workspace drafts and shared Meri registry. Public legal text and notices remain API-owned; legal memberships, monitor configuration, research selections and import decisions remain tenant-owned. The dense folder tracker is preserved.

The implementation includes exact retained document search/comparison; Florida statute and constitution revisions; rule notice history and published dates; six separately promoted statute-reference definitions; immutable monitor baselines; selective provider document hydration; additive prior-session datasets; citation-checked editable Workspace drafts; and reviewed internal report versions. Feature/process gates default off. The report runner owns scheduled monitor evaluation. No new message sender or capture service is introduced.

## Evidence and boundaries

- String citation identities preserve trailing zeros, article scope and subdivisions. Operative classification is conservative and parser-versioned. A reference, proposal, amendment adoption, enactment and provision effectiveness remain different evidence.
- PDF research extraction uses the existing extractor with explicit limits of 500 pages and 2,000,000 characters and retained native line breaks. Ordinary attachment defaults remain unchanged. Incomplete extractions cannot enter exact comparison.
- Search completeness requires an explicit selected-bill provider inventory and unchanged document/inventory fingerprints. A retained positive match does not establish a complete negative. Legal classification activation requires separately retained human qualification for the exact parser version.
- Monitor activation stores current source preview and a historical baseline; configuration or membership changes require review. Current owner/folder/client access is rechecked on reads and scheduled execution. Delivery and automatic follow-up are distinct controls and stay inactive for imported definitions.
- Selected historical datasets require exact prior provider sessions and reviewed dataset hashes, retain original ZIP bytes, and reuse canonical per-bill writers. Existing bills are retained or held on changed hashes. Current directory crosswalks, calendars and source-transition emissions are skipped. Historical client configuration uses separate capture-qualified assignment identities and its own supplied export.
- Research draft creation uses the existing atomic Workspace source-action receipt. Lost acknowledgments replay the same draft while preserving human edits. Current private access is enforced in Workspace reads and listings. Report approval pins the exact edited Workspace snapshot; later editing cannot rewrite an earlier report.
