# Business Development Phase 4 verification artifacts

The two JSON files in this directory are redacted, contract-shaped brief examples for release review. They intentionally omit tenant, user, conversation, internal-note, and contact identifiers. Their citations use public source record identifiers and locators already exercised during the authorized Phase 2 acceptance run.

- `example-brief-sam-identity.json` demonstrates an exact-identifier identity record, qualified firm fit, missing publication/event dates, and an edited practical action.
- `example-brief-usaspending-award.json` demonstrates an exact award amount, award stage, performance dates, a public locator, and the distinction between a verified award and an inferred strategic fit.

These are review fixtures, not production database exports and not claims of exhaustive provider coverage. `snapshotHash` and `sectionsHash` are labeled fixture values rather than production digests. Each factual statement cites an index in the same immutable version, and each cited record appears in that version's `sourceSnapshot.evidence` array.

Public source locators may redirect or require the source site's normal browser behavior. If a source becomes inaccessible, the product preserves the captured record identity and reports the limitation rather than rewriting the saved version.
