## Offline evidence and limits

Run from the repository root with Node built-ins only:

```powershell
node docs/engagement-preview-proposal-20261016/authorization/run-offline.cjs
```

`source-pins.json` records each baseline Git blob OID and SHA-256 of its actual UTF-8 blob bytes. Materialized files are compared after CRLF-to-LF normalization. Sparse-omitted files are read from the current Git index only when `git ls-files -v` confirms the skip-worktree marker. Ordinary missing files fail. The baseline must remain an ancestor of HEAD, with its exact pinned commit identity.

The serial tests use the actual immutable baseline strings for 40 in-memory source mutations: removed route guard/role/context, removed Clerk verification and tenant check, bypassed role rejection, removed tenant/archive predicates and locks, stale actor or missing Clerk correlation, removed grant stability/current wall decisions, weakened list discovery and cursor scope, skipped creation/aggregate gates, weaker history scope and missing tenant transaction setting. Each must produce a source-drift finding for the mutated file. These mutations never touch the source checkout and are **source-preservation checks**, not simulated user authorization decisions or a second implementation of the policy. Missing and additional source inputs also fail closed.

The baseline controller, access, RolesGuard and PostgreSQL test sources are pinned for reference. They were inspected, not rerun here. This packet runs no Nest/Clerk authorization, product database, live/native SQL, migrations, providers, HTTP/browser flows, paid jobs or heavy compiler. It establishes preserved source and a sensitive drift detector; it does not establish dynamic race behavior, current session validity, target database authority, or fresh runtime 401/403/404/503 coverage. Existing evidence remains separate and unchanged.

`offline-node-results.json` and `offline-node.tap` record the actual local serial run and its exit status. Pins should never be refreshed automatically to make a failed preservation check pass.
