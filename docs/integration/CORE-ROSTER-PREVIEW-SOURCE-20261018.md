## Authority and route

`main.ts` installs the roster gate immediately after `NestFactory.create`, before shared CORS, body parsers, route exclusions, and controller registration. It recognizes the reserved `core-roster-preview.capiro.ai` authority in both `rawHeaders`/Node's parsed Host and an absolute-form request target, so a mismatched Portfolio Host cannot fall through to ordinary resolution. It accepts only one exactly spelled Host and an origin-form `GET /api/clients` with matching raw and Express paths. The optional query is bounded to 512 raw bytes and unique `profileStatus`, `sectorTag`, and `includeArchived` keys with decoded values at most 160 characters. Existing DTO validation and `ClientsController.list` still reject archived-inclusive requests. Every reserved-host response is marked no-store before forwarding to parsers, including a parser error on an admitted GET. A duplicate, malformed, port-suffixed, trailed, or lookalike reserved Host, HEAD or another method/path, an absolute-form target, an encoded/trailed path, or an ambiguous query receives no-store 404. A correctly spelled reserved Host with either required flag off receives no-store 503. This process gate also covers health, webhooks, and internal paths excluded from tenant middleware, including direct VPC requests sent with that Host.

The first statement of `TenantContextMiddleware.use` mirrors the same decision before retained, execution, delegation, public, and ordinary paths. The admitted request uses existing `usePreviewNativeRead`: an unmarked live Clerk `sid`, online session check, and existing active local actor/member only. `PreviewNativeReadService.run` checks current membership before and after the application read. `ClientsService.listPreviewVisible` keeps tenant ID, current wall-visible IDs, and nonarchived status in the SQL predicate. The ordinary provisioning, rebind, self-heal, and `lastSeenAt` path is not used for roster Host traffic.

The composed Core task still serves the existing first-chat Host's native GET/HEAD and absolute-form read behavior. With native GETs on, Portfolio Host GET/HEAD routes that match the first-chat native route shapes remain unavailable, as in the parent source; they cannot fall through to ordinary provisioning or client listing. First-chat bootstrap and Meri service paths have no new route or credential behavior. The reserved roster Host cannot fall back to ordinary mode if its flag is off.
