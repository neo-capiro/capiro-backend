# Independent behavior-equivalence proof plan

Implementation starts only after parent path/retirement coordination. A frozen
source head/tree and exact implementation path list must precede independent
review. The audit is not a production behavior claim.

1. Retain the frozen switch body as a test-only baseline oracle with its exact
   Git blob/SHA, under inert fake ports. Compare a future candidate's actual
   dispatcher against this separately frozen body rather than generating both
   expectations from the candidate registry. Preserve the original failure and
   passing evidence; do not rewrite the oracle when a candidate differs.
2. Enumerate all 134 canonical core names and the five federal-market names
   independently from the shared registry. Prove core closure, exactly-one
   handler, no missing/extra/duplicate names and correct owner separation. This
   is name/set coverage, not a new hardcoded total or runtime catalog. No
   capability schema/description/surface/readOnly changes are part of the seam.
3. For every local case, compare trace order, exact object identity of `ctx` and
   `input` where currently forwarded, terminal receiver/method, argument count,
   order and optional values. Use distinct actor/input/proposal sentinels,
   repeated calls and concurrent synthetic calls to detect stale capture or
   cross-call contamination. Preserve grouped Portfolio/LegiWatch names as the
   actual selected name and test the exceptional `(input,ctx)` case.
4. For all cases, canceled/deadline fake control must stop before any owner
   access/call. Preserve the pre-dispatch assertion and existing scoped
   AsyncLocalStorage tests. Test unknown and inherited/prototype-like names,
   leading/trailing whitespace, and error identity. Raw `execute` unknown
   behavior differs from authenticated normalization; do not unify them.
5. Assert raw authenticated synchronous activity/parser/unknown failures and
   governed proxy's async rejection behavior separately. A sync terminal fake
   begins before the dispatch's first await; returned promises, thenables,
   synchronous throws, asynchronous rejections and result identity must have
   the same observable order. Do not introduce an `await` before invocation,
   schedule callbacks later, retry, or add a blanket catch.
6. Exercise every document format, absent/invalid format, optional district
   missing/nullish/falsey/result/promise cases, exact funding actor narrowing
   and all eight funding input shaping recipes. Test absent/present
   `actionProposalId` only for the three existing consumers; Excel/PowerPoint/
   replies must retain their current argument counts. Source-only fake ports
   must refuse any real provider, upload, mail, model or DB path.
7. Independently exercise the actual governed proxy with fake raw/Prisma/federal
   ports: tenant+current-user chart ownership/absence/unauthorized/missing
   dependency/bounds, current chart input, ordinary errors and governed memory
   outcomes. Test both public methods and optional execution forwarding.
   Federal names must bypass raw core dispatch as they do now. Retain all
   original proxy regression names and bodies.
8. Keep the actual Portfolio transport current-use helper unchanged. Use its
   existing fake conversation/grant regressions plus candidate dispatch to
   prove refusal before lazy owner lookup, missing owner behavior, current
   scope revocation/drift during awaited authority checks and final reread.
   The audit's fake wrapper only proves placement; it cannot prove these
   current-use semantics. Business-development and funding authority remain
   owned by their existing adapters and existing source-only suites.
9. Run the existing relevant provider-free suites after reviewing their import
   graph and fake ports: registration/manifest parity, governed memory/chart,
   request control, Portfolio current-use, award compatibility, and bounded
   approval/replay/client-scope coverage. Do not run scheduler-postgres or
   native/provider suites. Preserve source-literal regression assertions;
   any necessary equivalent structural rewrite needs explicit review of the
   same causal boundary and original failure coverage.
10. Compare exact source blobs outside the permitted implementation/test packet
    and keep all original test names, schema/registry/owner/classification and
    unknown controls. Perform strict focused source compilation/build using
    existing local generated declarations only. Publish an independently
    accepted draft with exact source/head/tree, path matrix, retained failures
    and checksum evidence; no main merge/deployment.
