## Source conclusions

The data envelope requires producer-specific top-level `resourceRevision` and all three actual request/normalization/context digests. The codecs require pinned Ed25519 keys, issuer, exact HTTPS origin, operation and recipient, a genuine supplied JCS provider, closed bounded input and canonical wire encoding. Their signature decision is explicitly insufficient for current authority. Data and authority-only probe purposes, headers and signing domains are distinct; the probe has no invented resource vector and cannot return a budget DTO.

The native capture admits only an actual request/context pair already present in the private middleware WeakMap. The receiving seam creates a private runtime brand only after invoking its supplied receiving codec; copied JSON projections cannot obtain it. It preserves original verified Clerk claims, selected membership/tenant and impersonation provenance without forwarding a JWT or constructing an authenticated HTTP request. Delegated native checks use a fresh online session followed by the existing local current identity owner, correlate the signed revision/principal and retain the original cutoff. This is source inspection of composition, not execution of a real Clerk/session path.

The current-resource composition uses actual selected membership plus canonical Portfolio or Intel owners and checks before/after drift. Portfolio detail and Changes still call their existing DTO owners; linked-client filtering and the Changes denied-client vector are preserved. Intel current facts use the canonical budget feature, current member, folder, client and unwalled-OR-grant owners, without an admin wall bypass, new client-name resolver, fiscal/asOf cutoff, account-assignment model or new business ranking policy. Unsupported canonical source selectors remain explicitly unavailable.

The HTTP helpers use constructor-pinned fixed URLs, supplied fetch, signed headers only, no redirect or user-credential fallback, bounded request/response JSON and deadline/AbortSignal checks. Core's Florida-native current endpoint intentionally introspects the authority-only probe for its intended Intel recipient; it rechecks only native facts and does not recursively read a Florida resource. Full Florida-data current checks use the full original data envelope and local/current resource observations. The private protocol is documented in [PRIVATE-PROBE.md](../backend-retained-authority/docs/retained-authority-20261016/PRIVATE-PROBE.md); it does not change a Meri public DTO or allocate workload trust.
