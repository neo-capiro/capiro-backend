## Decisions established before implementation

1. **Preserve canonical stores.** Saved prompts, workspace membership, feedback and governed-memory queues already have their own persistence and authorization. UI wiring/hydration defects do not justify duplicate stores. Meri document artifacts already have an authenticated lookup; repair clients of it.
2. **Reuse immutable evidence when it exists.** Messages persist retrieval metadata and a Context Packet ID, but the citation DTO/open-panel callback discards source-scope context. Trace the authoritative source association and persisted packet shape before choosing an additive field/migration. Old unknown scope must remain unknown.
3. **Read source content through its owner.** Mail supports authorized body continuation. Memory overview supplies exact-item read instructions and provenance. A source panel cannot promise full content from its current snippet-only DTO. Source identifiers, authorization, version and continuation must survive conversion into citations.
4. **Treat scope and counts as contracts.** The review queue is authorized across clients; display that honestly. A profile section’s total is not necessarily the whole call’s count. Inspect each adapter’s meaning before labeling it evaluated or complete.
5. **Keep provider reasoning intact.** No extra reasoning framework or legacy memory UI is required by these defects. Requested/effective provider details should stay distinct from lifecycle and evidence coverage.
