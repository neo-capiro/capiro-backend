No environment, collector, routing, model, credential, authorization, migration, deployment or production canary change is included.

Outgoing carriers identify actual SDK client spans. Existing signed governed-context admission, tenant/actor checks, source classification, deadlines, provider settlements and effect controls remain the authority owners. Existing JSON events continue, independently of the SDK sink.
