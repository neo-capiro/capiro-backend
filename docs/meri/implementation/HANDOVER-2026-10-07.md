## 5. Hazards learned

- **Long Bash commands.** A Bash command that outlives its 600 s timeout keeps running in the background, but output-dependent steps after it in the same command still run. Check the log's `EXIT` line before acting.
- **Plain `&`.** A background `&` in a Bash call may lose its local poller, while CodeBuild keeps running. Use `run_in_background`.
- **Heredocs.** Python heredocs turned `\b` and `\n` inside JavaScript regexes into control characters. Write source edits with the Edit tool.
- **`act` in React tests.** In a workspace test, `await screen.findByRole(...)` inside `act()` deadlocks, because updates are held until the callback returns. Find the element first, then click inside `act`.
- **Workspace window location.** The workspace reads `window.location`, so tests need a probe that copies the router's location into `history`.
