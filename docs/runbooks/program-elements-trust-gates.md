# Program Elements permanent trust gates (Phase K)

## Purpose

Make PE trust and SOC 2 checks permanent and executable on every release for
branch `agent/program-elements-final-closeout` / PR #705 and successors.

This runbook is **operational documentation**. It does not authorize shared-environment
migrations, ingestion commits, schedule deploys, LlamaParse, Secrets Manager pulls,
or email.

## Commands (from repo root)

```bash
pnpm -C apps/api run typecheck:pe-scripts
pnpm -C apps/api run lint:pe-scripts
pnpm -C apps/api run test:pe-trust
pnpm -C apps/api run verify:pe-phase-k
# optional offline prisma validate+generate (dummy DATABASE_URL is fine):
pnpm -C apps/api run verify:pe-migration-guards -- --validate-generate
```

Inherited PE gates remain:

```bash
pnpm -C apps/api run verify:pe-phase-a   # … through … verify:pe-phase-j
```

## What each permanent command covers

| Script | Coverage |
|---|---|
| `typecheck:pe-scripts` | Bounded TypeScript project `tsconfig.pe-scripts.json` (gate modules + metrics + catalog helpers). Catalog file list is exact — no globs. |
| `lint:pe-scripts` | Every production script path exists; no `_prisma_migrations` hand-edit; no `migrate resolve`; exact-SHA loaders registered; package scripts name exact tokens. |
| `test:pe-trust` | Jest: accuracy metrics (incl. grounded field + separated precision/recall/coverage/FP/FN), diagnostics fail-closed sizes, migration guard pure logic, metric/alarm catalog bounds, production script catalog honesty. |
| `verify:pe-phase-k` | DB-free executable chain: synthetic alarm events, diagnostic fixtures, grounded golden provenance (synthetic-loud). |

## Diagnostic fail-closed conditions

`scripts/lib/pe-trust-diagnostics.ts` treats these as **blockers** (gate fail):

- late / unobserved required sources
- null source-document observations
- duplicate observation groups
- stale reconciliation (open + past age threshold)
- old pending outbox (past age threshold)
- partial SAM runs / incomplete windows
- stale cache entries

Coverage gaps are **warnings** by default (honest incomplete coverage) unless
`forceCoverageGapsBlocker` is set by an operator policy.

Live SELECT-only report: `pnpm -C apps/api run diag:pe-trust` (requires `DATABASE_URL`;
do not point at production without Neo authorization).

## Migration guards

- Entrypoints must not reference `_prisma_migrations` in executable lines.
- Entrypoints must not run `prisma migrate resolve`.
- Exactly one active `migrate deploy` path among the entrypoint trio.
- Offline: `prisma validate` + `prisma generate` via `--validate-generate`.
- Clean migrate replay and upgrade replay: **disposable Postgres only**. Record exit codes;
  interpret with `interpretMigrateReplay()` (see unit tests). Never hand-edit
  `_prisma_migrations` — see `docs/runbooks/prisma-failed-migration-recovery.md`.

## Metrics and alarms (bounded cardinality)

Definitions: `apps/api/src/program-element/pe-trust-metric-catalog.ts`.

Rules:

- Dimension keys only: `source` | `family` | `severity`.
- `source` values are a fixed enum (no PE codes, no tenant UUIDs).
- Series upper bound must stay ≤ 256.
- Synthetic alarm test events are generated by `buildPeTrustSyntheticAlarmEvent`.
  Phase 8 documents them; it does **not** deploy EventBridge/schedule changes.

Existing CloudWatch wiring lives in `infra/cdk/lib/alarms-stack.ts` (`Capiro/ProgramElementSync`).
Adding wires is a separate infra deploy outside closeout Phase 8 deploy freeze — defs may land in catalogue + code, schedule deploys require Neo.

## Human-reviewed golden set

Blocked on human workstream (K6). AI may export candidates only.

| Rule | Enforcement |
|---|---|
| Synthetic rows loud warning | `auditGoldenReviewProvenance` + `grounded-field.golden.json` `_note` |
| Human rows need reviewer + date + SHA | same auditor |
| Never label AI synthetic as human reviewed | permanent gate asserts all committed grounded rows `humanReviewed === false` until replaced |

Domains expected in a real set (human workstream): RDT&E, procurement, O&M, committee marks,
enacted values, report language, awards, SAM links, personnel/contact use, current/outyear.

## Rollback / fix-forward

**Rollback PE Phase 8 product only** (example):

```bash
git revert <phase-8-product-sha>
# or reset branch to pre-K tip after coordination:
# git reset --hard <phase-7-pass-tip>
```

**Fix-forward** preferred when gates catch a real trust regression:

1. Keep release draft.
2. Land failing fixture as a regression test under `test:pe-trust`.
3. Fix pure helper / loader / diag.
4. Re-run `typecheck:pe-scripts lint:pe-scripts test:pe-trust verify:pe-phase-k`.

## Schedule ownership

Ingestion schedules remain owned by `infra/cdk/lib/ingestion-schedule.ts`.
Phase 8 verifies documentation and alarm **definitions** only — no schedule deploy.

## Integrity

Do not claim `test:pe-trust` green as human accuracy certification when goldens are synthetic.
Accuracy numbers from synthetic goldens are n/a or non-certifying.
