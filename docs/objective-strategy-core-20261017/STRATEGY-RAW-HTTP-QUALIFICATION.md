## Source change

Strategy `main.ts` now calls `configureStrategyBodyParsers` before Nest init.
The helper installs `objectiveGenerationRawBody` before the existing 8 MiB JSON
parser. Nest's ordinary parser registration stays enabled. CORS, validation,
global prefix, listener configuration and all authority providers are unchanged.

Capture applies only to the fixed workload-JWT generation routes under
`/strategy-api/internal/objective-canonical`:

| Method | Suffix | Entity bound |
| --- | --- | --- |
| POST | `generation-admissions`, `generation-requests`, `generation-acceptances`, `generation-completions`, `generation-terminals` | 1 byte through 8 MiB |
| GET | `generation-admissions/:generationJobId`, `generation-requests/:generationJobId`, `generation-completions/:generationJobId`, `generation-terminals/:generationJobId` | Exactly zero bytes |

GET IDs use the existing workload-JWT lowercase UUID grammar. The literal
`originalUrl` match excludes query strings, case/encoding/trailing aliases and
absolute-form targets. Unregistered `generation-producer/admit` and
`planner-applications` retain their existing parser behavior and authority owner.

POST capture uses the JSON parser's verify hook before character decoding,
BOM removal or JSON interpretation. It retains parsed `@Body()` objects and
stores an independent byte copy as an own, nonenumerable, nonwritable,
nonconfigurable `rawBody` data property. No parsed-body serialization is used.
Empty entities and skipped media types cannot become captured proof. Malformed
JSON cannot reach a consumer, even if its exact entity was observed by verify.

Framed GETs use a zero-byte binary parser. Normal Meri GETs have no entity
framing and body-parser skips them, so capture instead observes the actual
stream end with zero data. Already consumed, aborted or closed streams remain
unavailable; owned listeners are removed on one terminal outcome. Nonidentity
content encoding is refused on matched routes, rather than inflating signed
bytes. Ordinary JSON decompression, form parsing and the 8 MiB limit are kept.

This is a transport prerequisite, not authentication or native authorization.
It deliberately retains the existing JSON media/charset grammar, including
UTF-16 JSON parsing. It does not select a new UTF-8-only grammar or authenticate
duplicate original headers. The eventual Strategy credential extractor must
own those decisions and require actual captured bytes. A semantic canonical
selector hash remains distinct from the workload token's entity-byte digest.
