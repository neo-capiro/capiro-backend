# `run_analysis` credential availability — source-only correction

Date: 2026-09-25. The provisional source branch now requires a nonblank `CLIO_SANDBOX_TOKEN` as well as the existing sandbox switch, URL and tenant feature flag before reporting `run_analysis` available. The sandbox's `/run` endpoint returns 401 whenever its configured bearer token is absent. Previously an API deployment with no token could offer a tool whose calls were guaranteed to fail. The same `analysisSandboxEnabled()` gate is used by legacy final-schema filtering, the V3 capabilities path used by the managed assistant, and the API execution path. Raw schema registration is unchanged; the final model-facing offer is conditional.

Focused source regressions were authored for missing, empty and whitespace-only tokens, blank URL, disabled switch, tenant opt-out, configured path, and execution refusal before any sandbox fetch. Independent static review found no code or type issue. These tests have **not run** under the user's host-memory hold; neither source qualification nor deployed acceptance is claimed.

This is a configuration prerequisite, not JEV eligibility or sandbox readiness. A wrong token, unreachable runner, full queue, rate limit, failed Python spawn or missing analysis libraries can still cause a call to fail. `/healthz` is unauthenticated process liveness and can report `ok` even without a token. Phase 3 must keep `runtimeAvailability: unresolved`, `eligibility: unresolved`, and `executable: false` until an authenticated, bounded, capability-specific and fresh readiness observation exists and the invocation path rechecks its policy. Clientless conversations must not be forced through the three existing client-only proof checks when a dark `run_analysis` permission row is later added. JEV remains default-off.

Acceptance after the hold requires the focused Jest cases, exact API and orchestrator typechecks/builds, off-mode/model-facing schema parity, and a guarded runner/image contract. Final browser QA, after the user approves the exact release, must use only `https://os.capiro.ai`.
