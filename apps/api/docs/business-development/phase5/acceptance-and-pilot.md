## Pilot scorecard (thresholds fixed before review)

Hard gates:

- cross-tenant access: `0`;
- duplicate recipient deliveries under replay/overlap: `0`;
- confident ambiguous-identity alerts: `0`;
- unreviewed amount/stage/date errors in the acceptance sample: `0`;
- provider-network calls from the evaluator: `0`;
- partial/error checks that advance a complete baseline: `0`.

Record, without changing thresholds after seeing results:

- alerts emitted, duplicates skipped, backfills/suppressed decisions, and quiet decisions sampled;
- true material / useful alerts and false positives;
- read and dismiss counts, prospects advanced to a next action, watch pauses/opt-outs;
- source health and age, publication-to-first-observed lag, evaluator duration and cap hits;
- provider/LLM credits attributable to the evaluator (expected `0`) and database cost per useful alert.

## Rollout sequence

1. Merge the reviewed SHA and deploy additive schema and images with the global flag initially off.
2. Register the DB-only evaluator schedule against the same reviewed API digest.
3. Enable global Phase 5 plus both tenant flags for `capiro-internal` only.
4. Establish quiet baselines and run replay, overlap, partial/error, backfill, source-link, notification, Meri, and pause/rollback checks.
5. Review alert and quiet-decision samples with product/evidence/operations owners.
6. Add a fixed named tenant cohort only after the hard gates pass. Broad default-on and email remain separate decisions.

Any hard-gate failure stops expansion and uses `operations-and-rollback.md`. Existing source ingestion is never disabled or duplicated as a watch rollback step.
