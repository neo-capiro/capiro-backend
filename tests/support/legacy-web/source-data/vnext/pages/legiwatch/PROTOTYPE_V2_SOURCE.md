# LegiWatch v2 implementation source

Design source: `Capiro LegiWatch v2(2).html` and `LEGIWATCH-V2-HANDOFF(4).md`.

Implementation rules:

- Inter for product typography; IBM Plex Mono for metadata and status labels.
- Cool surface palette: `#EFF1F5`, `#FFFFFF`, `#101828`, `#294E68`.
- Committees is a primary destination.
- Hearings is split into Schedule, My Sessions, and Archive.
- Follow and Attend are separate actions.
- Client Lens changes private analysis only, never public facts.
- Phase 9 operational controls are never user-facing.
